# web-business

Workspace for building a $10K/month web services business (Nairobi Stack Studio — tech company for startups & SMEs).

- `BUSINESS-PLAN.md` — refined strategy, offer ladder, phases, targets
- `ACTION-PLAN-30-DAYS.md` — Phase 0 + Phase 1 day-by-day
- `OUTREACH-SCRIPTS.md` — WhatsApp/IG/LI/Upwork scripts + tracking
- `sales-site/` — Next.js + Tailwind sales site (run: `cd sales-site && npm run dev`)

## Before launch checklist
- [ ] Replace `WHATSAPP_NUMBER` in `sales-site/src/app/page.tsx`
- [ ] Replace `you@example.com` in the contact form (or wire up Formspree/Resend)
- [ ] Build 3 demo restaurant sites and link them in "Recent work"
- [ ] Deploy sales-site to Vercel (`npx vercel`)
- [ ] Create one-page client agreement (scope, 50% upfront, revisions, timeline)
