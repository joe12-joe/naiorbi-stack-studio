# 30-Day Action Plan — Phase 0 + Phase 1

## Week 1 — Assets
- Day 1: Lock niche (restaurants & cafes). List 10 restaurants you like; note what their online presence looks like.
- Day 2: Build demo site #1 (fictional Nairobi restaurant — menu, hours, WhatsApp button, photos via Unsplash).
- Day 3: Build demo site #2 (cafe — landing page focus).
- Day 4: Build demo site #3 (grill house — with ordering flow mockup).
- Day 5: Customize sales site; replace WhatsApp number + email; proofread copy.
- Day 6: Set up Google Business Profile, Upwork, Fiverr, LinkedIn Services, PayPal/Wise. Create one-page agreement template (50% upfront, scope, revisions, timeline).
- Day 7: Deploy sales site (Vercel free tier) + demos (Vercel subdomains or Netlify). Test on phone.

## Week 2 — Proof + setup
- Day 8: Screenshot demos; write 3 short "case study" blurbs (problem → built → result) for each.
- Day 9: Set up link-in-bio for Instagram; create @ handle for the studio; post first demo video (screen recording, 30 sec).
- Day 10: Build list of 100 Nairobi restaurants/cafes with weak/no websites (Google Maps + Instagram + Facebook). Columns: name, area, IG, phone/WA, website?, notes.
- Day 11: Test message 5 warm contacts (friends/family with restaurant connections) for feedback on sales site.
- Day 12: Polish sales site from feedback; add demos + testimonials placeholders.
- Day 13: Set up simple CRM: spreadsheet with columns (business, contact, channel, date sent, status, next action).
- Day 14: Rest + review. Goal: every asset ready, zero excuses.

## Weeks 3–4 — Outreach sprint (full-time hours)
- Daily: 15–20 outreach messages (WhatsApp/IG/LinkedIn/Maps leads) using OUTREACH-SCRIPTS.md. Log everything.
- Daily: 1 LinkedIn/X post; 2 short videos/week.
- Day 15–16: Offer free mini-audit to anyone who replies; aim to book 2 calls/day.
- Day 17–18: Send quotes; close first discounted client ($150–$300).
- Day 19–21: Deliver client #1 (use template system); collect testimonial + Google review + referral names.
- Day 21: Post case study #1 publicly.
- Day 22–24: Continue outreach (new batch of 50 leads); close client #2.
- Day 25: Deliver #2; testimonial + referrals.
- Day 26: Upwork/Fiverr: send 10 proposals/day using demo portfolio.
- Day 27: Ask both clients for referrals; deliver retainer pitch to each.
- Day 28: Deliver client #3 if closed; else close one with launch-offer urgency ("3 slots at $150, 1 left").
- Day 29: Weekly review: numbers vs targets (outreach, replies, calls, closes, revenue). Adjust niche/message/channel based on data.
- Day 30: Plan Month 2 (Phase 2): standard pricing, retainer push, content cadence.

## Targets for day 30
- 3 clients closed (even discounted) · $500–$1,500 collected · 3 testimonials · 1–2 retainers started · 200+ outreach messages sent · all assets live.

## Rules
- No discount without testimonial + Google review + 2 referral names.
- 50% upfront always. Simple written agreement always.
- If reply rate < 8% after 50 messages: fix message; if reply → call < 25%: fix offer/price; if call → close < 20%: fix sales call (record? ask for feedback).
- Never work without payment confirmation.
